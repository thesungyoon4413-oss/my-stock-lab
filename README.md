# MY STOCK LAB — 개인 투자 기록실 2.9.0

한국어 개인 투자 기록 웹사이트입니다. 기존 GitHub Pages 주소와 금고 형식·비밀번호·보고서 수신키를 유지합니다. 실제 투자 자료는 공개 저장소에 넣지 않습니다.

- 국내·미국 보유·시세·평가손익, 매매·실현손익, 배당·커버드콜 총수익을 출처와 실제 기준일로 관리합니다. 미확인 값은 추정하지 않습니다.
- 기존 예약 보고서는 암호화해 같은 사이트의 수신함에 전달합니다. 원본 예약은 유지하며 금고를 열면 기기에서 복호화합니다.
- 공식 ETF·공시 자료 자동 수신과 원본 보고서의 후보 확인·가상 성과 검증을 지원합니다. 유료 AI·금융 API를 호출하지 않습니다.
- 금고는 기기 안에서 AES-256-GCM으로 저장하며 파일 백업과 기기 내 자동 복구점을 지원합니다.
- 승인된 Supabase Free 프로젝트에 로그인하고 원본 기기를 지정하면 변경된 금고의 암호문을 자동 보관할 수 있습니다. 인증 세션은 선택한 기기에 별도로 암호화 보관하며 금고 백업에 포함하지 않습니다.

## 외부 백업

설정 → 외부 암호화 자동 백업 → 백업 계정 로그인에서 프로젝트에 만든 본인 계정을 사용합니다. 이 기기를 백업 원본으로 확인하면 금고가 열린 동안 5분 간격으로 변경을 점검합니다. 최대10MB·최근3개·최근24시간4회 저장을 보호 한도로 두며, 한도 응답 후24시간 대기합니다. 다른 기기는 첫 복원 후 변경을 확인할 수 있습니다. 로컬 변경이 다르면 자동 덮어쓰기를 멈춥니다.

복원은 기기 안에서 비밀번호·암호문·구조를 검증하고 기록 수를 확인한 뒤 진행합니다. 저장 완료 전에는 현재 금고를 교체하지 않습니다. 실제 소유자 계정의 첫 저장·복원 확인은 사용자 기기에서 수행합니다. 초기 프로젝트 설정은 setup/ 안내와 UPGRADE-v2.9.md를 참고하세요.

추가 운영비0원 조건으로 GitHub Pages Free·공개 저장소의 표준 무료 Actions·Supabase Free만 사용합니다. 결제수단 등록·유료 전환·유료 API·자동 충전은 사용하지 않습니다. 서비스 무료 정책의 영구 유지는 보장할 수 없고, Free 프로젝트는 저활동 시 일시중지될 수 있습니다. 앱 종료·금고 잠금 중에는 해당 기기의 백업이 멈춥니다.

토스증권의 조회 전용 키 미제공·CORS 미지원 조건 때문에 주문 가능한 계좌 키를 연결하지 않습니다. 파일 가져오기와 직접 수정을 지원합니다. 국내 시세 지연, 해외 주식·환율 기준일과 누락은 화면에 표시합니다. 실제 세금 확정과 수익을 보장하지 않습니다.

Linux WebKit·Chromium 자동 검사는 실제 iPhone 하드웨어 검사와 구분합니다. 개인 PDF·원장·금융 API 키·비밀번호·복호화키를 소스·로그·공개 저장소에 추가하지 마세요.
