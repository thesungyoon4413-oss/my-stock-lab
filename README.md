# MY STOCK LAB 2.7.0

개인 투자 기록을 기기 안에 암호화 저장하는 한국어 웹 앱입니다. 공개 저장소에는 일반 코드·수신 공개키·암호문만 두며 개인 원장·평문 보고서·금융 API 키는 게시하지 않습니다.

## 사용

같은 사이트 주소와 Safari 저장 공간에서 금고를 엽니다. 기존 금고·비밀번호·원장·수신키 형식은 유지됩니다. 새 금고를 만들거나 기존 자료를 다시 등록할 필요가 없습니다. Safari 공유 메뉴로 홈 화면에 추가할 수 있습니다.

- 기존 ChatGPT 국내·미국 보고서는 암호화 수신함으로 전달되면 금고를 열 때 자동으로 받습니다. 열린 동안 10분 간격으로 재확인합니다. 원본 채팅 링크와 기존 보고서는 보존합니다.
- 배당금·분배금 메뉴에서 실제 받은 종목별 금액, 원장 기반 커버드콜 손익, 운용사 공식자료를 함께 확인합니다. NAV 추이·분배락일·지급일·공시 분배율·추정 ROC의 실제 기준일을 표시합니다.
- 공식 분배 일정은 예정 정보입니다. 미공시 금액·분배락일 당시 보유 수량·입금액을 추정하지 않으며 배당 장부에 자동 합산하지 않습니다. 공시 ROC는 추정치이며 최종 세무 분류와 구분합니다.
- 투자 기회 메뉴는 받은 보고서의 명시된 신규 추천 구간을 기기 안에서 추출합니다. 원문과 가격을 한 번 확인하면 최초 추천을 고정해 성과를 추적합니다. 가격이 없으면 연결된 무료 시세를 확인할 수 있으며 추천일 이후 가격으로 과거 기준가를 만들지 않습니다.
- 무료 실적 비교는 보유 미국 기업과 편집 가능한 관찰 목록을 손익계산서·재무상태표로 순환 조회합니다. 기존 시세 자동 갱신과 무료 연결이 켜져 있으면 금고를 열 때 하루 최대 2개 기업을 점검합니다. 재무자료는 7일간 재사용하고 시세와 최근 24시간 20회 안전 한도를 공유합니다.
- 실적 비교는 같은 통화·같은 결산일을 확인하며 분기 전년 동기 성장률, 연간 평균 자본 ROE, 부채비율을 표시합니다. 금융업·업종 차이, 밸류에이션·뉴스·촉매를 검증한 매수 추천과 구분합니다. 정성 근거와 PER 등 누락 값은 만들어내지 않습니다.
- 시세를 갱신하면 보유 커버드콜의 기초자산과 확인된 추천·비교지수도 같은 무료 한도 안에서 조회합니다. 시세가 없거나 지연되면 이전 자료의 실제 기준일을 유지합니다.
- 암호화 백업 내보내기는 열린 금고의 키로 복호화·구조·내용 일치를 검사한 뒤 다운로드를 요청합니다. 파일 앱의 실제 보관 여부는 확인해야 합니다. 별도 백업 검증은 현재 금고를 덮어쓰지 않습니다.

## 추가 운영비 0원 구조

GitHub Pages 정적 호스팅과 기기 저장을 사용합니다. 운용사 자료 수집은 공개 저장소의 표준 ubuntu-latest GitHub Actions 러너에서 하루 한 번 실행합니다. 저장소가 public이 아니면 작업을 실행하지 않습니다. 유료 AI·금융 API·대형 러너·유료 도메인·크레딧 구매·자동 충전을 사용하지 않습니다. 기존 ChatGPT 예약은 현재 계정의 포함 한도 안에서 사용하며 별도의 유료 API로 우회하지 않습니다.

공식 ETF 수집은 10:43 KST를 목표로 하지만 GitHub 예약은 지연될 수 있습니다. 운용사 robots.txt가 허용한 공개 상품·일정 페이지에서 숫자와 날짜 일부만 저빈도로 읽고, 원문 HTML은 게시하지 않습니다. 결과는 수신 공개키로 암호화합니다. 공식 API 이용 계약이나 실시간 제공을 보장하는 구조는 아닙니다. 조회 실패 시 원인을 기록하고 이전 검증 자료와 기준일을 유지합니다.

무료 미국 시세는 사용자가 동의한 Alpha Vantage 키, 국내 시세는 공공데이터포털 금융위원회 V2 키를 기기 금고에 보관합니다. 앱은 최근24시간 제공자별20회 안전 한도와 요청 간격을 유지합니다. 외부에서 같은 키를 쓴 호출은 집계할 수 없습니다. 공개 코드·채팅에 키를 붙여넣지 않습니다.

## 확인 범위와 제한

원장 기반 배당·매매·평가·추가 세금은 별도로 집계합니다. 종목 미분류 세금이나 원가 미확인은 임의 확정하지 않습니다. 개인 총손익은 거래내역서·현재 시세·수령 분배금·근거 있는 세금 배분 기준의 참고값이며 확정 세무 신고액이 아닙니다.

추천은 실제 매수와 별개인 가상 기록입니다. 관측 수익률은 분할·병합·분배금 미보정 가격 수익률이고, 동일 기준일 비교지수가 있을 때만 초과수익을 계산합니다. 전체 시장을 유료 AI 없이 자동 분석했다고 주장하지 않습니다. 재무 선별은 보유 기업과 관찰 목록·등록 근거의 규칙 비교이며 전체 시장 탐색이 아닙니다. 국내 재무 직접 연결·공시 원문 자동 수집은 아직 제공하지 않습니다. SEC·DART 공시 검색 링크를 제공합니다.

토스는 읽기 전용 키와 CORS를 제공하지 않는다는 공식 회신에 따라 현재 보안 조건에서 계좌 API를 연결하지 않습니다. 비밀번호·주문 가능한 키·비공식 로그인 자동화를 사용하지 않습니다. 검토한 거래내역서 묶음과 파일·직접 입력을 지원합니다.

금고 비밀번호를 잊으면 복구할 수 없습니다. 기기 데이터 삭제·기기 분실에 대비한 백업이 필요합니다. 서버 금고나 기기 간 자동 동기화는 제공하지 않습니다. 실제 iPhone 하드웨어 검증과 브라우저 엔진·반응형 검사를 구분합니다.

## 2.7.0: 공식 공시·기업 발표와 기기 내 복구점

국내·미국 보고서 화면에 DART 회사별 공시 RSS와 NIKE IR RSS를 연결했습니다. DART는 공개 연구 범위 8개 기업, 미국은 NKE 발표를 지원합니다. 수집당 기업별 최근 12건의 제목·발표 시각·원문 링크만 보관합니다. DART 회사별 RSS는 최근 5영업일을 제공하며 빈 RSS를 ‘과거 공시 없음’으로 해석하지 않습니다. 알파벳 등 범위 밖 종목은 직접 연결되지 않았다고 표시합니다. 전체 언론 뉴스·공시 원문 자동 해석을 제공한다고 주장하지 않습니다.

공식 RSS는 표준 무료 공개 GitHub Actions에서 07:43 KST 매일·16:43 KST 평일을 목표로 수집하며 지연될 수 있습니다. robots.txt를 확인하고 저빈도 조회하며 공시 본문은 수집하지 않습니다. DART가 반환한 다른 기업의 관련 공시나 맞지 않는 날짜·URL은 제외합니다. 암호문과 목록만 발행하고 평문은 임시 폴더에서 삭제합니다. 기존 투자 보고서·추천·판단을 대체하지 않습니다.

금고 저장 시 변경 전 암호문을 최근 3개와 하루 첫 저장 3개까지 같은 기기 안에 자동 보관합니다. 설정의 ‘기기 내 자동 복구점’에서 해당 시점 비밀번호를 기기 안에서 확인하고 복원하거나 암호화 파일로 보관합니다. 저장소 사용이 차단되거나 부족하면 복구점 생성은 중지하지만 기본 금고 저장을 막지 않습니다. 이 기능은 외부 자동 백업·기기 간 동기화가 아니므로 기기 분실·브라우저 저장소 삭제에는 별도 암호화 백업 파일이 필요합니다.

무료 수동 WebKit 검증 작업은 합성 자료만 사용하고 개인 금고·증권 API 키를 읽지 않습니다. Linux WebKit 검사와 실제 iPhone 하드웨어 검증은 구분합니다.
