무료 백업 연결 준비

승인한 Supabase Free 프로젝트에서 한 번 실행하는 보안 설정입니다. 이 페이지는 금고나 인증정보를 읽거나 전송하지 않습니다.

1

기본 보안 설정

아래 코드를 복사하고 Supabase SQL 편집기에 붙여넣은 뒤 Run을 누르세요. 결과에 MSL_BACKUP_SCHEMA_READY와 3이 나오면 설치된 상태입니다.

소유자 등록 전에는 모든 사용자 접근이 차단됩니다. 암호화 백업만 저장하며 최대 10MB·최근 3개·최근 24시간 4회 저장으로 제한합니다.

2

백업 로그인 계정 한 개 만들기

Supabase Authentication → Users ↗에서 Add user → Create user로 본인 계정 한 개를 만듭니다. 이메일과 백업 로그인용 비밀번호를 입력하고 이메일 확인 옵션을 선택하세요.

Supabase 관리 화면 로그인과 별개인 MY STOCK LAB 백업 로그인 계정입니다. 금고 비밀번호와 데이터베이스 비밀번호는 입력하지 않습니다. 이 페이지나 채팅에 인증정보를 보낼 필요가 없습니다.

3

유일한 계정을 소유자로 등록

본인 계정 한 개가 준비되면 아래 코드를 SQL 편집기에 붙여넣어 Run을 누르세요. 결과에 MSL_BACKUP_OWNER_READY가 나오면 등록됐습니다. 계정이 없거나 둘 이상이면 등록을 멈춥니다.

다음 연결 단계

보안 설정 후 프로젝트 API Keys ↗의 Publishable key를 앱 연결에 사용합니다. 비밀키·관리자 키·데이터베이스 비밀번호는 브라우저 앱에 넣지 않습니다.

이 페이지의 코드 복사만으로 백업이 활성화되지는 않습니다. 실제 앱 로그인과 저장·복원 검증이 끝난 뒤 활성화합니다. 요금제는 Free로 유지하고 결제수단을 등록하지 않습니다.
